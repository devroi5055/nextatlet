# Frontend: Configuration

Everything you configure in the frontend: environment variables and the config files.

## Environment variables

### Public, validated in `src/config/env.ts`

Zod-validated at startup ([`env.ts`](https://github.com/devroi5055/nextatlet/blob/main/apps/NextAtlet.Client/src/config/env.ts)):

| Variable | Required | Default | What it does | Example |
|----------|----------|---------|--------------|---------|
| `NEXT_PUBLIC_API_URL` | **yes** | — | Backend **origin only** (the generated client adds `/api`) | `http://localhost:5278` |
| `NEXT_PUBLIC_ENABLE_API_MOCKING` | no | — | `'true'`/`'false'`, toggles MSW | `false` |
| `NEXT_PUBLIC_URL` | no | `http://localhost:3000` | This app's base URL; CORS origin for the mock server | `http://localhost:3000` |
| `NEXT_PUBLIC_MOCK_API_PORT` | no | `8080` | Mock server port | `8080` |

### Auth0 SDK vars (read directly by the library, not by `env.ts`)

| Variable | Required | What it does |
|----------|----------|--------------|
| `AUTH0_DOMAIN` | yes | Auth0 tenant domain, e.g. `nextatlet-dev.eu.auth0.com` |
| `AUTH0_CLIENT_ID` | yes | Regular Web App client id |
| `AUTH0_CLIENT_SECRET` | yes | Client secret |
| `AUTH0_SECRET` | yes | Session-cookie encryption key (a long random string) |
| `APP_BASE_URL` | yes | This app's base URL (`http://localhost:3000`) |
| `AUTH0_AUDIENCE` | **effectively yes** | Must equal an Auth0 API Identifier **and** the backend's `Authentication:Audience`. Unset → the backend can't decrypt the token. See [Authentication](./authentication.md). |
| `AUTH0_SCOPE` | no | Defaults to `openid profile email offline_access` |

### `.env` template

There is **no `.env.example`** in the repo (only `.env.example-e2e` for Playwright). Create `apps/NextAtlet.Client/.env`:

```dotenv
NEXT_PUBLIC_API_URL=http://localhost:5278

AUTH0_DOMAIN=your-tenant.eu.auth0.com
AUTH0_CLIENT_ID=your-client-id
AUTH0_CLIENT_SECRET=your-client-secret
AUTH0_SECRET=generate-a-long-random-string
APP_BASE_URL=http://localhost:3000
AUTH0_AUDIENCE=https://api.nextatlet.dk
```

> Never commit real secrets. `.env` is gitignored.

### Package manager

The frontend uses **pnpm 9** (`packageManager: "pnpm@9.15.0"` in `package.json`). Run `corepack enable` once and pnpm is provisioned automatically at the pinned version — no global install needed. `.npmrc` sets `node-linker=hoisted` so `node_modules` is laid out flat (like npm/yarn), which keeps this template — originally built for yarn with loose peer deps — working without changes.

## The generated API client (`src/types/api.ts`)

Generated by **swagger-typescript-api** — it exports an `Api` class that `src/lib/api-client.ts` instantiates. The client supports a `customFetch` hook, which is how the bearer token is injected.

### ⚠️ The codegen pipeline is broken

The `package.json` scripts do **not** regenerate this file correctly:

```json
"gen:api":   "pnpm gen:spec && pnpm gen:types",
"gen:spec":  "dotnet swagger tofile --output ./openapi/swagger.json ../NextAtlet.Api/bin/…/NextAtlet.Api.dll v1",
"gen:types": "openapi-typescript ./openapi/swagger.json -o ./src/types/api.ts"
```

Three problems:
1. `gen:types` runs **openapi-typescript**, which emits a `paths`/`components` map — **not** the `Api` class the app depends on. Running `gen:api` would overwrite `api.ts` with an incompatible shape and break `api-client.ts`.
2. `gen:spec` writes to `./openapi/`, which **doesn't exist**.
3. The DLL path `../NextAtlet.Api/…` is wrong — the backend is at `../NextAtlet.Server/NextAtlet.Api/…`.

**Do not run `pnpm gen:api`** without fixing the generator to use swagger-typescript-api and the correct paths.

## Known issues

- **`tailwind.config.cjs` is inert.** Under Tailwind v4 with `@tailwindcss/postcss` and no `@config` directive in the CSS, this v3 config is never loaded. Consequences: `tailwindcss-animate` and `@tailwindcss/typography` are **not active**, so `animate-in` / `fade-out-0` / `zoom-in-95` / `slide-in-from-*` classes (dialog, drawer, dropdown) and `prose` (MDPreview) **do nothing**.
- **`text-primary-gold` / `bg-primary-gold/15` generate no CSS** — the tokens are `--color-primary` and `--color-gold-*`, never `--color-primary-gold`. These classes are used in several components and silently produce nothing.
- `pnpm lint` fails (`next lint` removed in Next 16); `prepare: husky` runs but there's no `.husky/` dir.
- `import 'dotenv/config'` in `env.ts` pulls a devDependency toward the client bundle.
